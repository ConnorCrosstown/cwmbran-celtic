# Cwmbran Celtic AFC — Full Site Audit (2026-07-08)

Method: 8 parallel read-only audits — security, correctness, accessibility, SEO,
performance, code quality, UX/content, dependencies. Findings are deduplicated
and **re-ranked holistically** (each agent rated within its own lens; severity
below is site-wide). Builds on `AUDIT-2026-04-26.md` and `AUDIT-2026-05-20.md`
— items already fixed are listed at the end, not re-reported.

Current state: 38/38 tests pass, `tsc --noEmit` clean, `next build` succeeds,
site LIVE at cwmbran-celtic.vercel.app. The issues below are pre-existing (most
predate the recent allwalessport/season-ready work).

## P0 — Critical (data loss, money, security, or broken core)

**1. Public forms silently discard submissions — users told "we'll be in touch."**
- Contact form has no `onSubmit`/action and no `/api/contact` route — native GET, message lost (`src/app/contact/ContactClient.tsx:142`).
- Celtic Bond signup (the **revenue funnel**) — no submit handler (`src/app/celtic-bond/page.tsx:167,250`).
- Volunteer + Sponsor-inquiry forms write only to `sessionStorage` then show a "Thank you, someone will be in touch" screen — leads never reach the club (`src/components/forms/VolunteerForm.tsx:104-114`, `SponsorInquiryForm.tsx:93-103`).
- **Fix:** wire each to a real endpoint (Resend email to the club, or a durable store) with genuine success/error state. A confident false "success" is worse than a visible error.

**2. Newsletter email validation is a no-op.** `validateEmail()` returns a `{isValid,…}` object (always truthy), so `if (!email || !validateEmail(email))` only checks emptiness — any garbage string is accepted, stored, and sent to Resend (`src/app/api/newsletter/subscribe/route.ts:24`). **Fix:** `!validateEmail(email).isValid` (the volunteer/sponsor forms already do this correctly).

**3. Newsletter subscribers + social posts persist to the local filesystem — non-durable on Vercel.** `fs.writeFile` to `process.cwd()/data/*.json` (`src/lib/newsletter.ts:56-59`, `src/lib/social-media.ts:64-65`). Vercel function FS is read-only outside `/tmp`, and `/tmp` is ephemeral/per-instance → signups throw `EROFS` (generic 500) or vanish on the next cold start; unsubscribe tokens later 400 as "invalid link." Also a read-modify-write **race** with no locking (`addSubscriber`, `newsletter.ts:66-99`). **Fix:** move to Vercel KV/Postgres/Blob before relying on newsletter in prod.

**4. Social-post API endpoints have zero authentication.** `POST /api/social/posts`, `PUT/DELETE /api/social/posts/[id]`, `POST /api/social/generate` — no auth anywhere (`src/app/api/social/**`). Today `publishPost()` only console.logs (stubbed), but it's built to go live once `TWITTER_*`/`FACEBOOK_*`/`INSTAGRAM_*` tokens are set → **unauthenticated "post as the club."** **Fix:** bearer/session-gate all three before any live posting is wired.

**5. `/admin` has no server-side auth.** `src/lib/auth.ts` is entirely browser-side (localStorage); no `middleware.ts`; `/admin/*` returns 200 to anonymous requests (still open from AUDIT-2026-05-20 P0-6). **Fix:** gate `/admin/*` in `middleware.ts` with an httpOnly session cookie from a real server login route.

**6. Wrong match-day pricing shown to fans.** Home/footer show £5/£3/free (`src/app/page.tsx:161`, `Footer.tsx:234`) while `/tickets` + `/fixtures` show £7.50/£5/free (`fixtures/page.tsx:255`) — both hardcoded, not read from `ticketPricing.matchDay` (still open from AUDIT-2026-05-20 P0-4; only a TODO was added). **Fix:** point all surfaces at one source of truth.

**7. Expired promo banner live on 3 pages.** `SeasonTicketBanner` (`variant="topbar"` on `/teams`, `/fixtures`, `/news`) unconditionally shows "EARLY BIRD until 31st January 2026" + "2025/26 SEASON TICKETS" — 6 months expired. The `/tickets` page was fixed with a date guard; the shared component wasn't (`src/components/banners/SeasonTicketBanner.tsx:23,29,87,91`). **Fix:** apply the same `earlyBirdActive` guard inside the component.

**8. Fake phone number as a live CTA.** "Call: 01633 000000" (`tel:+441633000000`) on the membership page (`src/app/membership/page.tsx:335`); the real number `07831 441109` is used elsewhere. **Fix:** real number or link to `/contact`.

**9. `robots.txt` points crawlers at the dead domain's sitemap.** `sitemap:` hardcoded to `https://cwmbranceltic.com/sitemap.xml` (403s) while everything else migrated to `SITE_URL` (`src/app/robots.ts:10`). **Fix:** `` sitemap: `${SITE_URL}/sitemap.xml` ``.

**10. CI is red on every push — `npm run lint` is broken.** `next lint` was removed in Next 16.2.6, and there is no ESLint installed or configured at all; `.github/workflows/ci.yml` runs the failing script (`gh run list` shows consecutive failures). No lint/dead-code safety net exists. **Fix:** install `eslint` + `eslint-config-next` (flat config `eslint.config.mjs`), point the script at `eslint .`.

## P1 — High (visible breakage, performance, accessibility, SEO coverage)

### Performance
- **342KB cheerio chunk ships to the browser.** Client components (`HeroSection`, `MatchStatusBanner`, `NextMatchHero`) import format helpers from `src/lib/comet.ts`, which transitively imports the cheerio-based scraper — no `import 'server-only'` boundary (verified in the client manifest). **Fix:** split `comet.ts` into a server-only data module + a tiny client-safe `format.ts`; add `import 'server-only'`.
- **443KB hero image not via `next/image`.** `HeroSection.tsx:87` uses a CSS `background-image` (2048×1152 baseline JPEG, no AVIF/WebP/priority) — the LCP element on the homepage. **Fix:** `next/image` with `priority`/`fill`, resize + modern formats.
- **Crest sources oversized for a 40px badge** — `newport-corinthians.png` 244KB@900px, `new-inn.png` 219KB, etc. **Fix:** pre-resize to ~200×200 before commit.
- **Site-wide raw `<img>`** for club logo (`Header.tsx:70`, `Footer.tsx:58`), sponsor logos (footer, every page), and gallery grid/lightbox — no `next/image`, no width/height (CLS/LCP; partly still open from AUDIT-2026-05-20 P2-9, now broader). **Fix:** migrate to `next/image` with explicit dimensions.

### Accessibility (WCAG 2.1 AA)
- **Monogram contrast fails AA** — `hsl(hue,55%,40%)` + white text drops to ~2.84:1 (hue ~60°); below 4.5:1 for ~half the hue space (`src/lib/team-crest.ts:17-21`). Only shows for crest-less opponents (women's/cup), but real. **Fix:** fix lightness to ~25-28% (verified ≥4.5:1 across 0-360°) or use a curated AA-safe palette.
- **Nav dropdowns are keyboard-inaccessible** — desktop submenus open only on `onMouseEnter` (`src/components/layout/Navigation.tsx:146-184`); keyboard users can't reach child links. **Fix:** open on focus, add `aria-haspopup`/`aria-expanded`.
- **Modals lack dialog semantics + focus trap** — `SearchModal` and `GalleryViewer` have no `role="dialog"`/`aria-modal`, no focus trap, no focus restore, incomplete Escape handling; background stays in tab order (`src/components/ui/SearchModal.tsx`, `gallery/GalleryViewer.tsx`). **Fix:** use a real dialog primitive (Radix / focus-trap-react).
- **Unlabelled email input on every page** — the footer newsletter (`inline` variant) has only a placeholder, no `<label>` (`src/components/newsletter/NewsletterSignup.tsx:44-67`, rendered in `Footer.tsx:46`). **Fix:** add `sr-only` label (the `card` variant already does).
- **Form status not announced** — success/error messages have no `aria-live`/`role="status"` (newsletter all variants; `VolunteerForm` success swap). **Fix:** wrap in a live region (`VolunteerForm.tsx:148` already does it for errors).
- **No reduced-motion support** — no `@media (prefers-reduced-motion)` anywhere despite marquee/ticker/steam/fade animations; `PageTransition` ignores `useReducedMotion()` (`src/app/globals.css`, `PageTransition.tsx`). **Fix:** global reduced-motion override + gate framer-motion.
- Mobile nav panel stays focusable when closed (needs `inert`/`aria-hidden`) (`Header.tsx:171`); role toggles missing `aria-pressed` (`VolunteerForm.tsx:224`); `PlayerCard` div-as-button pattern (`PlayerCard.tsx:15`).

### Correctness / robustness
- **Unparseable feed dates propagate as NaN** — if allwalessport changes the `<h2>` date format, `parseAwsDate` → `NaN`, silently: fixtures with `NaN` date vanish (`NaN > now` false), results render "Invalid Date" live, and `stableMatchId(NaN,…)` collides → React key clashes (`src/lib/allwalessport-parse.ts:7-15`, `allwalessport.ts:26-56`). **Fix:** log + drop NaN-dated rows in the parser.
- **Source outage looks identical to "no results yet."** Since the results mock fallback was removed, an allwalessport failure and a legitimate empty pre-season both return `{results:[]}` with no distinguishable signal/alert (`src/lib/comet.ts:184-194`). **Fix:** surface a distinguishable log/metric when all active teams fail.
- **`getOppositionByName` can resolve the wrong club** — the fuzzy fallback strips suffixes then does bidirectional substring matching in array order, so `"Newport Corinthians FC"` can match the historical `newport-city` entry first → wrong ground/badge/history (`src/data/opposition-data.ts:245-272`). **Fix:** require exact cleaned-name match before substring, or prefer longest match.
- Match dates formatted without explicit `timeZone` (off-by-one for UTC+13/14 users) (`comet.ts:349`).

### SEO
- **Sitemap missing ~25 indexable routes** — `/players` (+ profiles), `/programme` (+ matches), `/away-days`, `/membership`, `/hospitality`, `/club/*`, reserve teams, etc. (`src/app/sitemap.ts`). **Fix:** generate dynamically like news/gallery already are.
- **Duplicate brand suffix in `<title>`** — two pages hand-append `| Cwmbran Celtic AFC` on top of the layout template → `X | Cwmbran Celtic AFC | Cwmbran Celtic AFC` (`sponsors/boards/page.tsx:14`, `ban-the-bovril/page.tsx:9`). **Fix:** drop the manual suffix.
- No OG/Twitter on dynamic routes (players/news/gallery/away-days/archives `generateMetadata` set title/desc only); programme routes are client components with no `generateMetadata`; `/fans/potm` has no metadata.

### UX / content
- **Stale "2025/26" season labels everywhere** — players, programme, shop (`kit-2025-26.jpg`), membership, kit/season-ticket banners all still say last season (`src/app/players/page.tsx:52`, `KitReveal.tsx:13`, `membership/page.tsx:189`, …). Reads as a year out of date. **Fix:** bump to 2026/27.
- **Stale news** — newest article is 2026-01-11; nothing on relegation/pre-season/Ardal (`src/data/news-data.ts`). Homepage "Latest News" shows a 6-month-old top story.
- **Programme "Recent Results" uses last season's mock** (Carmarthen/Treowen — not even in Ardal) for every 2026-27 programme (`src/app/programme/[slug]/page.tsx:121`). Plus every programme prints a blank "Founded:" for the 16 Ardal opponents (`ProgrammePreview.tsx:693`). **Fix:** drop/guard those sections until real Ardal data.
- **"Latest Result" heading with a blank gap** pre-season — the `SectionHeader` renders even though `LatestResult` returns `null` (`src/app/page.tsx:112`, `LatestResult.tsx:18`). **Fix:** render a "No results yet — season starts …" placeholder.
- Season-archives missing the just-completed 2025-26 season (`src/data/season-archives.ts`).

### Security / deps
- **Dead SofaScore module + weak webhook still live** — `src/lib/sofascore.ts` (489 lines) + `src/app/api/sofascore/route.ts` (317 lines) are unreachable from the app, but the route is a public webhook with secret-in-query-string auth (log-exposed), no HMAC/rate-limit, and an arbitrary-file-read `import` action. **Fix:** delete both (nothing imports them), or if the Apify path is wanted, re-wire + harden.
- `/api/newsletter/subscribe` has no rate limiting (still open); CSRF helpers (`src/lib/csrf.ts`) are defined but wired into nothing.
- **Production dependency vulns:** `ws` 8.x high-severity (DoS + memory disclosure) via `isomorphic-dompurify → jsdom → ws`; `dompurify` 3.4.5 moderate (8 XSS-bypass CVEs, fix in 3.4.11). Both fixable via `npm audit fix` (non-breaking).

### Code quality
- **`ProgrammeData` redeclared in 6 files with divergent shapes** (+ `SquadPlayer` 3×, `Opposition` dup in ProgrammePDF, local `Fixture`/`Result` in 3 files) — a renamed field silently stops flowing with no compiler error (`programme/**`, `ProgrammePDF.tsx:65`, …). **Fix:** one canonical `src/types/programme.ts`, import everywhere.
- **~1,050 lines of dead code** — `src/data/welsh-translations.ts` (233 lines, zero importers) + the SofaScore module/route/`scripts/import-sofascore.ts` (~800 lines). **Fix:** delete or wire up.
- **Programme rendering duplicated 4 ways, ~5,600 lines** (`programme/[slug]/page.tsx`, `print/page.tsx`, `ProgrammePDF.tsx`, `ProgrammePreview.tsx`) — every section reimplemented per surface; content changes need 3-4 hand edits. **Fix:** extract shared per-section data builders.
